# VRC Favorite World History

VRChatのお気に入りワールド名と変化を、利用者自身のブラウザ内に残すWindows版Google Chrome拡張です。

ワールドがお気に入り一覧から見えなくなったあとも、最後に確認できた名前・作者・確認日時を振り返れます。名前の変更、お気に入り一覧からの消失、APIからのアクセス不可と、その後の復帰も履歴に残します。

通常4個、VRC+加入時は最大8個のお気に入りリストと、利用者が付けたリスト名にも対応します。8リスト×100件の800ワールドを一括比較し、どの位置のワールドが消えても記録対象にします。

> [!IMPORTANT]
> APIだけでは「作者による削除」「非公開化」「利用者自身がお気に入りを解除」を確実に区別できません。本ツールは観測できた事実を、それぞれ「現在アクセス不可」「お気に入り一覧にない」と表示します。

## 利用者向けインストール

Node.jsやコマンド操作は不要です。

1. Windowsインストーラーを入手し、配布時に提示されたファイル名とSHA-256が一致することを確認してから実行します。コード署名をしていないため、WindowsのSmartScreenが警告する場合があります。
2. インストーラーは管理者権限やUACを要求せず、現在のWindowsユーザー用の `%LOCALAPPDATA%\Programs\VRCFavoriteWorldHistory\extension` へ拡張を配置します。インストール先は変更できません。
3. 完了画面から、Chromeの `chrome://extensions/` と配置済みの `extension` フォルダーを開きます。
4. Chromeの「デベロッパー モード」を有効にします。
5. 「パッケージ化されていない拡張機能を読み込む」を押し、手順3で開いた `extension` フォルダーを選びます。
6. ツールバーへ本拡張を固定します。

Downloads内のインストーラーは導入後に削除できます。固定場所の `extension` フォルダーは、拡張を使っている間は移動・削除しないでください。

### 更新

自動更新はありません。新しいバージョンのインストーラーを入手したら、必要に応じて先に画面の「設定とバックアップ」からJSONバックアップを保存し、Chromeの全ウィンドウを閉じてから実行します。インストーラーはChromeを強制終了しません。同じ版の再インストールはできますが、古い版へのダウングレードは拒否します。

更新時は現在の `extension` を同じアプリフォルダー内の `extension.old` へ一時退避し、新版の配置に成功したら退避分を削除します。配置に失敗した場合だけ旧版へ戻し、複数世代のロールバックは保持しません。

## 最初の使い方

1. 拡張の「VRChat公式サイトを開く」を押します。
2. 開いた公式サイトで、普段どおりログインします。
3. 拡張へ戻り「今すぐお気に入りを確認」を押します。
4. 初回確認が終わったら「記録と設定を詳しく見る」で一覧を確認します。

パスワード、2FAコード、Cookie値をこの拡張へ入力する画面はありません。初回確認は比較の基準を保存するため、過去に起きた変更をさかのぼって復元することはできません。

## 記録する内容

- 現在または過去に確認できたワールド名、作者名、World ID
- お気に入りリストの現在名・過去名と、ワールドが最後に属していたリスト
- お気に入り一覧に見つかった最後の日時
- 名前変更、お気に入り一覧からの消失・復帰、アクセス不可・復帰の履歴
- お気に入りリスト間の移動履歴
- 同期日時と、秘密を含まない固定分類のエラー状態

一時的なAPIの揺らぎを変更と誤認しにくくするため、消失とアクセス不可は正常な確認が2回続いた時点で確定します。初回の一覧保存では通知を出しません。

## 自動確認と通知

- 既定では約12時間ごとに、固定時刻を避けるランダムな遅延を加えて確認します。
- ブラウザが終了している間は動作せず、次回起動後に再開します。
- VRChat公式サイトのログイン期限が切れた場合は、再度公式サイトでログインしてください。
- 名前変更や確定した状態変化は、ブラウザのデスクトップ通知で知らせます。
- OS通知を見逃しても、拡張アイコンの未読件数と履歴画面で確認できます。
- 自動確認と通知は設定画面から個別に無効化できます。

## プライバシーと安全性

- 記録は拡張専用のIndexedDB（ブラウザ内DB）だけに保存します。
- 開発者のサーバー、広告、アクセス解析、クラウドDBはありません。
- 外部通信先は `https://api.vrchat.cloud/` だけです。公式サイトを開く操作を除き、任意のURLへ通信しません。
- VRChat公式サイトの既存ログインをブラウザに自動送信させますが、拡張はCookie APIを要求せず、その値を読み取り・保存・書き出ししません。
- API操作は読み取り専用GETだけです。
- バックアップにはワールド記録と安全な表示設定だけを含め、セッション状態は含めません。復元前に形式と内容を厳格に検査します。
- バックアップにはお気に入り名や表示名が含まれるため、公開場所へアップロードしないでください。
- サーバーDB、SQLite、PostgreSQLは使いません。DBはChromeの現在のブラウザプロフィール内でだけ動き、利用者や開発者が別途起動・保守する必要はありません。

## 容量とアンインストール

通常の800ワールドでは利用者によるメンテナンスは不要です。通信は約12時間ごとの同期時だけ行い、API応答をブラウザキャッシュへ保存しません。障害調査用の同期記録は自動的に直近100件へ整理します。過去のワールド名と変更履歴は本ツールの目的そのものなので自動削除せず、保存量が大きくなった場合だけ設定画面で警告します。

アンインストールは次の順序で行います。

1. 必要なら「バックアップを書き出す」を押します。
2. 拡張の設定画面で「記録をすべて削除してアンインストール」を使います。この操作は同期を止め、拡張専用IndexedDB内の利用者記録を単一処理で全消去してからChrome側の拡張を削除します。消去できない場合は削除へ進みません。
3. その後、Windowsの「インストールされているアプリ」から本製品をアンインストールし、固定場所のファイルを削除します。

Windows側のアンインストーラーは、Chrome側の削除完了をプロフィールから自動判定しません。また、Chromeのプロフィール、Cookie、IndexedDB、書き出したJSONバックアップ、Downloads内のインストーラーを探索・削除しません。Windows側だけを先に削除してもブラウザ内記録の消去にはならないため、必ず上の順序で操作してください。

詳しくは[セキュリティ設計](docs/SECURITY.md)と[プライバシー方針](docs/PRIVACY.md)を参照してください。

## 現在の制約

- 対象環境はWindows版Google Chromeのデスクトップ版です。Edge、複数プロフィール、スマートフォン版は動作検証の対象外です。
- VRChat APIは公式の安定した公開仕様ではなく、予告なく変わる可能性があります。異常な応答は記録へ反映せず、安全側で同期を停止します。
- ワールドが変化してから次の正常な同期までの間は検知できません。
- お気に入り一覧からの消失は全800件を比較しますが、アクセス不可の個別確認はAPI保護のため1同期20件です。1回404確認済みのワールドを次回優先し、残り件数を画面に表示します。
- WebSocketは認証セッションをURLへ含めるため使用しません。
- Chrome Web Store経由の配布、ブラウザポリシーによる強制導入、自動更新は行いません。更新は新しいインストーラーを手動で実行します。
- コード署名を行わないため、ファイル名とSHA-256を確認した場合でもSmartScreenの警告が残る可能性があります。
- インストーラーはサービス、スケジュールタスク、スタートアップ、テレメトリ、実行時ダウンロードを追加しません。

本プロジェクトはVRChat Inc.の公式製品ではなく、同社による承認・提携を示すものではありません。

## 開発と検証

必要環境はNode.js 22以降です。

```bash
npm ci
npm run verify
npm run package
```

`npm run verify` はlint、厳格なJavaScript型チェック、テスト、公開物の権限・秘密情報・外部資産検査、ビルドを実行します。`npm run package` は同じ検証済み `dist/extension` からChrome用ZIPとWindowsインストーラー、および各SHA-256を `artifacts/` に生成します。インストーラーだけを再作成する場合は `npm run build:installer` を使います。いずれのインストーラー生成にもWindows上のInno Setup 6が必要です。生成物はGit管理しません。

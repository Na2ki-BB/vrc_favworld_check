# VRC Favorite World History

VRChatのお気に入りワールドを記録し、一覧から消えたりアクセスできなくなったりしたときに、最後に保存した名前や画像を確認できるGoogle Chrome拡張です。記録は、利用中のパソコンのChrome内に保存します。

[最新版をダウンロード](https://github.com/Na2ki-BB/vrc_favworld_check/releases/latest) · [変更履歴](CHANGELOG.md) · [プライバシー方針](docs/PRIVACY.md)

> 記録できるのは、導入後に確認できた情報です。記録を始める前に消えたワールドや、保存できなかった画像は復元できません。

## できること

- ワールド名、作者名、World ID、お気に入りリスト、サムネイルを保存
- 名前・所属リストの変更、お気に入り一覧からの消失、アクセス不可と復帰を記録
- 消えた可能性のあるワールドを一覧表示し、確定した変化を通知
- 名前・作者・リスト名・World IDで検索し、リストや状態で絞り込み
- 不要な記録を非表示にし、必要に応じて表示へ戻す・完全削除する
- 名前、変更履歴、保存済み画像をまとめてバックアップ・復元

VRChatのお気に入り自体を追加・変更・削除する機能はありません。また、ワールドの削除、非公開、自分でお気に入りから外した場合を、取得情報だけで区別することはできません。

## 必要な環境

- Windows 10以降
- Google Chrome 120以降（最新版を推奨）
- VRChatにログインして利用する、Chromeの通常プロフィール

Chromeが終了している間は確認しません。シークレットモードでの利用は対象外です。通常アカウントの4リストと、VRC+の最大8リストを扱います。

## インストール

### Windowsインストーラーを使う

1. [GitHub Releases](https://github.com/Na2ki-BB/vrc_favworld_check/releases/latest)を開き、注意事項を確認して、Assetsから `vrc_favworld_check-installer-v<バージョン>.exe` をダウンロードします。
2. インストーラーを実行し、画面の案内に沿って進めます。完了画面では、Chromeと `extension` フォルダーを開く項目を選んだまま「完了」を押します。
3. 開いたChromeの拡張機能画面で「デベロッパー モード」をオンにし、「パッケージ化されていない拡張機能を読み込む」を押します。
4. 手順2で開いた `extension` フォルダーを選びます。
5. Chrome右上の拡張機能メニュー（パズルのアイコン）から「VRC Favorite World History」をピン留めします。

インストーラーはファイルを配置します。**Chromeへの追加は、手順3・4の操作が必要です。** 配置先は次の固定フォルダーです。インストール後も移動・削除しないでください。

```text
%LOCALAPPDATA%\Programs\VRCFavoriteWorldHistory\extension
```

Chromeが自動で開かなかった場合は、アドレスバーへ `chrome://extensions/` と入力してください。フォルダーが開かなかった場合は、エクスプローラーのアドレスバーへ上の配置先を入力できます。

### ZIPを使う場合

インストーラーを使わない場合は、同じリリースの `vrc_favworld_check-v<バージョン>.zip` を展開し、`manifest.json` があるフォルダーを上の手順3・4で読み込みます。以後も同じ場所を使うため、ダウンロード用の一時フォルダーではなく、保管場所を決めて展開してください。GitHubが自動生成する「Source code」のZIPは、配布用の拡張ZIPとは別です。

### 警告と権限の確認

配布インストーラーはコード署名されていないため、Windows SmartScreenなどの警告が出る場合があります。上記リポジトリのリリースから取得したことと、リリースに記載された注意事項を確認してください。SHA-256が掲載されている場合は、ダウンロードしたファイルと照合できます。配布元やファイルを確認できない場合は実行しないでください。

Chromeに接続先の権限が表示された場合は、次の4つを確認します。各権限の用途は[プライバシー方針](docs/PRIVACY.md#chromeの権限)に記載しています。

- `vrchat.com`
- `vrchat.cloud`
- `api.vrchat.cloud`
- `files.vrchat.cloud`

## 使い方

### 最初の記録を保存する

1. Chromeのツールバーで拡張アイコンを押します。
2. 「VRChat公式サイトを開く」から公式サイトでログインします。二段階認証も公式サイトで完了してください。
3. 拡張へ戻り、「今すぐ確認」を押します。
4. 確認が終わったら「保存済みの記録を見る」を開きます。要確認のワールドがあるときは「名前と画像を見る」と表示されます。

最初の確認は、現在のお気に入りを比較の基準として保存します。変更履歴と通知は、次回以降に確認できた変化から作成します。画像は順番に保存されるため、名前の記録が終わっても画像の取得が続く場合があります。

### 記録と変更履歴を見る

記録画面では、消えた可能性のあるワールドを最初に表示します。

| 状態 | 意味 |
| --- | --- |
| 現在アクセス不可 | ワールド情報を取得できない状態が続いています |
| お気に入り一覧にない | 取得したお気に入り一覧に見つからない状態が続いています |
| 確認中 | 1回の確認で変化を検出し、次の確認を待っています |

一時的な通信失敗と区別するため、消失・アクセス不可は、有効な取得結果で同じ状態を2回確認してから確定します。同じワールドが複数の条件に当てはまっても、要確認件数は1件です。

- 現在のお気に入りも見る場合は、「すべての記録・検索」を開き、「表示するワールド」を「すべての記録（非表示を除く）」に切り替えます。
- 名前や作者を検索し、「お気に入りリスト」で絞り込めます。
- 「変更履歴」では名前やリストの変更、消失・復帰を確認できます。開いた履歴は既読になります。
- 「非表示の記録」では、一覧から隠した記録を確認できます。

### 自動確認と通知

初期設定では、Chrome起動中に約12時間ごとに確認します。通信を分散するため、実行時刻には最大1時間の幅があります。Chrome終了中に予定時刻を過ぎた場合は、次回起動後に確認を再開します。

「設定とバックアップ」の「自動で確認する」と「デスクトップ通知」で、それぞれの有効・無効を切り替えられます。手動で確認する場合は「今すぐ確認」を押してください。

「現在のログイン確認」は、ログイン状態だけを調べる表示です。お気に入りを同期する「今すぐ確認」とは別で、結果を最大60秒再利用します。「前回の同期結果」は、最後に実行した確認の結果を表示します。

### 記録を非表示にする・戻す・完全削除する

消失が確定したカードの「削除」は、確認後にその記録を通常の一覧から隠します。名前・画像・履歴は残り、同期と通知も続きます。「非表示の記録」の「戻す」で再表示できます。ワールドが復帰しても、非表示は自動解除されません。

「非表示の記録」の「完全に削除」は、確認後に対象の名前・画像・履歴を消去する操作です。取り消せません。再表示を防ぐためWorld IDだけを残し、後日の通常確認で利用可能なお気に入りとして取得できた場合は、新しい記録を始めます。古い記録は戻りません。

どちらの操作もVRChat側のお気に入りは変更しません。詳しい動作は[記録管理仕様](docs/RECORD_MANAGEMENT.md)を参照してください。

## 保存データとバックアップ

名前、履歴、画像、設定は、この拡張を読み込んだChromeプロフィール内に保存します。別のパソコンやChromeプロフィールへ自動同期する機能はありません。

サムネイルは最大辺320pxの小さな画像として保存します。「画像の保存状況」、または記録画面の「記録の状態・画像の保存状況」で進捗を確認できます。画面を閉じてもChrome起動中は取得を続け、Chrome終了後は次回起動時に再開します。「今すぐ確認」を繰り返し押す必要はありません。

### 書き出す

「設定とバックアップ」→「バックアップを書き出す」で、表示中のアカウントの記録と保存済み画像を1つのZIPファイルへ保存します。名前、作者、リスト、変更履歴、非表示状態、削除済みID、自動確認・通知の設定を含みます。

画像はChrome内に保存済みのサムネイルだけです。書き出すために画像を再取得することはなく、未保存の画像は含まれません。Cookieやパスワードも含みません。表示名やお気に入り情報を含むため、自分だけが扱える場所へ保管してください。

### 復元する

「バックアップを復元する」でZIPファイルを選び、アカウント、記録・履歴・画像の件数、書き出し日時を確認します。対象アカウントの記録、設定、非表示状態、削除済みIDをバックアップの内容へ置き換えます。他アカウントの記録は残ります。

ZIP内の画像は追加・更新します。ZIPに含まれない既存画像は残しますが、バックアップで完全削除済みとされるIDの画像は消去します。古いバックアップに名前や履歴が残っていれば、完全削除した記録が復元される場合があります。

以前のJSONバックアップ（version 1・2・3）も同じ操作で復元できます。JSONには画像が含まれないため、画像はファイルから戻りません。

## 更新

1. 必要な記録と保存済み画像をバックアップします。
2. Chromeのウィンドウをすべて閉じます。
3. [最新版のリリース](https://github.com/Na2ki-BB/vrc_favworld_check/releases/latest)から、新しいインストーラーを取得して実行します。
4. Chromeの拡張機能画面で、本拡張が有効で、バージョンが更新されていることを確認します。古い版が表示されている場合は、本拡張の「再読み込み」を押します。
5. 拡張で「今すぐ確認」を押します。

ZIPで導入した場合は、Chromeを閉じてから、同じ読み込み先フォルダーの拡張ファイルを新しいZIPの内容で置き換え、手順4へ進みます。

記録を引き継ぐため、同じWindowsユーザー・Chromeプロフィール・読み込み先フォルダーを使ってください。更新のためにChromeから拡張を削除しないでください。別のフォルダーを新しく読み込むと、以前の記録へアクセスできなくなる場合があります。

## 利用を終了する

1. 必要な記録と保存済み画像をバックアップします。
2. 「設定とバックアップ」の「記録をすべて削除して拡張を削除」を押し、確認内容を読んで実行します。
3. Chromeから拡張が削除された後、Windowsの「インストールされているアプリ」から「VRC Favorite World History」をアンインストールします。ZIPで導入した場合は、保管していた拡張フォルダーを削除します。

手順2は、この拡張が保存した全アカウントの記録と画像を削除します。手順3は、配置した拡張ファイルを削除します。書き出したバックアップファイルは残るため、不要なら保存先で削除してください。

## 注意事項・トラブルシューティング

| 表示や症状 | 確認すること |
| --- | --- |
| ログインが必要 | 同じChromeプロフィールのVRChat公式サイトでログイン・二段階認証を完了し、拡張で「今すぐ確認」を押します |
| ログイン後も「現在のログイン確認」が変わらない | 表示された確認時刻から60秒以上たってから「再確認」を押します。前回の同期失敗は、次の同期が成功するまで残ります |
| VRChatが混雑している・回数制限中 | 画面に表示された時刻まで待ちます。連続して確認を押さないでください |
| 通信できない | インターネット接続を確認し、時間をあけて再確認します |
| VRC+のリストが4個しか表示されない | VRC+用リストのワールドを取得できると最大8枠を認識します。対象リストにワールドがある状態で再確認してください |
| 画像を自動保存中・待機中 | Chromeを起動したまま待ちます。自動確認を無効にしていても、開始済みの画像保存は続きます |
| 一部の画像を取得できない | 画面に対処の案内があれば従います。時間をあけて次の確認を行うと再試行します。保存済みの画像や履歴は残ります |
| 更新後も古い版が表示される | `chrome://extensions/` で本拡張を再読み込みし、読み込み先が更新したフォルダーか確認します |
| 完全削除後、アイコンが「?」になった | 旧形式の履歴では未読の内訳を特定できない場合があります。「変更履歴」を開くと既読になり、通常表示へ戻ります |

VRChat APIやChromeの仕様変更で動作しなくなる可能性があります。最新の注意事項は[リリースページ](https://github.com/Na2ki-BB/vrc_favworld_check/releases/latest)を確認してください。

不具合は[GitHub Issues](https://github.com/Na2ki-BB/vrc_favworld_check/issues)へ報告できます。拡張とChromeのバージョン、症状、再現手順を記載してください。Issuesは公開されるため、パスワード、二段階認証コード、Cookie、トークン、バックアップ内容を投稿しないでください。

# VRC Favorite World History

VRChatのお気に入りワールドを今から記録し、あとで消えたときに名前と画像で思い出すためのGoogle Chrome拡張です。

一度記録を始めると、ワールドがお気に入り一覧から見えなくなった場合や、現在アクセスできなくなった場合でも、最後に保存できた名前・作者・お気に入りリスト・サムネイルを確認できます。記録はこの拡張を入れたパソコンのChrome内に保存されます。

> [!IMPORTANT]
> この拡張が残せるのは、最初の確認以降の記録です。導入後、最初に「今すぐ確認」を押して現在のお気に入りを保存してください。

## このツールでできること

- 消えた可能性のあるワールドを、記録画面の最初にまとめて表示します。
- 最後に確認できたワールド名、作者名、World ID、サムネイル、お気に入りリストを残します。
- ワールド名の変更、お気に入り一覧からの消失と復帰、アクセスできない状態と復帰を履歴に残します。
- 変化が確定したときは、デスクトップ通知と拡張アイコンの件数で知らせます。
- 記録を検索し、JSONファイルへバックアップできます。
- 通常アカウントの4リストと、VRC+で利用できる最大8リストに対応します。

削除、非公開、自分でお気に入りから外した場合は、VRChatから同じように見えることがあります。画面には、取得できた状態に合わせて「現在アクセスできません」または「お気に入り一覧にありません」と表示します。

## 対応環境

- Windows版Google Chrome 120以降
- デスクトップ版Chromeの通常プロフィール1つ

Chromeは最新版へ更新してから利用してください。

## インストール

このREADMEと一緒に受け取った、ファイル名が `vrc_favworld_check-installer-v` で始まる `.exe` ファイルを使います。

1. インストーラーをダブルクリックします。
2. 画面の案内に沿って進みます。最後の画面では、「Chromeでバージョンと権限を確認する」と「選択するextensionフォルダーをエクスプローラーで開く」の2つにチェックが付いたまま「完了」を押します。
3. Chromeの「拡張機能」画面と、`extension` フォルダーが開きます。
4. Chrome右上の「デベロッパー モード」をオンにします。
5. 「パッケージ化されていない拡張機能を読み込む」を押します。
6. フォルダーを選ぶ画面で、手順3で開いた `extension` フォルダーを選びます。
7. Chrome右上のパズルマークから「VRC Favorite World History」を探し、ピンのマークを押します。

`extension` フォルダーには拡張本体が入っています。インストール後も同じ場所に残してください。

### Windowsの青い警告が出たとき

このインストーラーでは、Windowsが「PCが保護されました」と表示する場合があります。このREADMEと一緒に受け取ったファイルであることを確認し、「詳細情報」から「実行」を押します。

### Chromeが権限を表示したとき

接続先に次の4つのVRChatサイトが表示されていることを確認して、追加を許可します。

- `vrchat.com`
- `vrchat.cloud`
- `api.vrchat.cloud`
- `files.vrchat.cloud`（サムネイル画像の配信先）

ほかのサイトも表示された場合は、このツールを渡した人へ確認してください。

### 配布ファイルを詳しく確認したい場合（任意）

SHA-256は、受け取ったファイルと配布時のファイルが同じかを照合するための文字列です。配布案内にSHA-256と確認方法が記載されている場合は、手元のインストーラーと照合できます。

## 最初の記録

1. ツールバーの拡張アイコンを押します。
2. 「VRChat公式サイトを開く」を押し、公式サイトでいつもどおりログインします。
3. 拡張へ戻り、「今すぐ確認」を押します。
4. 確認が終わったら「記録とサムネイルを見る」を開きます。

最初の確認では、今のお気に入りを今後の比較基準として保存します。変化の通知は、次回以降の確認から始まります。

## 消えたワールドを確認する

記録画面は現在のお気に入りも含めて表示し、次のワールドを先頭に並べます。「すべての要確認」を押すと、変化を確認したいワールドだけに絞れます。

1. 「現在アクセス不可」と確認できたワールド
2. お気に入り一覧に見つからなくなったワールド

同じワールドが両方に当てはまる場合も、要確認件数は1件として数えます。カードには、アクセスできた時点で保存した名前、画像、作者、お気に入りリスト、World IDが表示されます。

一時的な通信の乱れと区別するため、同じ状態が正常な確認で2回続いたワールドを要確認として表示します。最初の確認は「確認中」と表示し、次回に見つかった場合は通常のお気に入り表示へ戻します。

要確認が0件のときは「現在、要確認のワールドはありません」と表示されます。状態の絞り込みを変えると、現在のお気に入りや確認中のワールドも見られます。お気に入りリストの絞り込みでは、VRChatで付けたリスト名を選べます。

## 自動確認と通知

初期設定では、Chromeを開いている間に約12時間ごとに確認します。実行時刻には0～60分の幅があります。

消えた可能性のあるワールドが確定した場合は、名称変更などよりも優先して通知します。通知は件数を知らせ、名前と画像はクリック後の記録画面に表示します。拡張アイコンにも件数が残ります。

自動確認と通知は「設定とバックアップ」で個別に停止できます。Chromeを次に開いたとき、自動確認の予定も再開します。

## サムネイルと保存場所

サムネイルは、ワールドへアクセスできる間に取得し、見分けるために十分な小さい画像へ縮小してChrome内へ保存します。ワールドがあとからアクセスできなくなっても、保存済みの画像は残ります。

v0.1.7以前には画像の保存機能がありません。更新後に「今すぐ確認」を押すと取得を始めます。すでにアクセスできなくなったワールドの画像は、過去に保存していなければ復元できません。記録画面では、画像が未保存の場合と、保存画像の読み出し・表示に失敗した場合を分けて案内します。

「今すぐ確認」を一度押すと、画像は残りも自動で順番に保存されます。何度も押す必要はありません。記録画面とポップアップで保存済み件数と残り件数を確認できます。この画面を閉じてもChrome起動中は処理が続き、Chromeを終了した場合は次回起動後に再開します。

更新直後など、自動保存の進捗がまだない場合も保存済み画像数を表示します。この場合、残り件数は未確認として案内し、記録ワールド数から推測しません。保存状況を読み込めない場合も、件数欄を隠さず案内を表示します。

通信への負担を抑えるため、画像は最大100件・30秒ごとに区切り、通常は約1分の間隔をあけて続きを取得します。保存済みで変更のない画像は再取得しません。通信制限中は指定時刻まで自動で待ち、取得できない画像は回数を区切って再試行します。「一部の画像を取得できませんでした」と表示されても、保存済み画像と履歴は残ります。800ワールド分の画像をすべて最大サイズで保存した場合でも、画像の合計は約40MBです。

設定の「自動確認」は約12時間ごとのお気に入り確認です。これを無効にしていても、自分で開始した今回の画像保存は完了まで続きます。

名前、履歴、画像は通常、利用者が「記録をすべて削除して拡張を削除」を実行するまでChrome内に残ります。ただし、Chromeから直接拡張を削除した場合、Chromeプロフィールを削除・初期化した場合、端末や保存領域が故障した場合は失われることがあります。使用量が大きくなった場合は設定画面でバックアップを案内します。

## バックアップ

「設定とバックアップ」の「バックアップを書き出す」から、ワールド名や変更履歴をこの拡張用のバックアップファイル（JSON形式）へ保存できます。お気に入り情報を含む個人用ファイルとして、自分だけが扱える場所へ保管してください。

JSONバックアップには名前や変更履歴を保存し、サムネイルはChrome内の記録に保管します。復元後、アクセスできるワールドの画像は次回確認で取得します。アクセスできないワールドのサムネイルは、現在のChrome内にある保存画像が唯一の記録になるため、拡張を削除するときは先に確認してください。

## 更新

新しい版のインストーラーを受け取ったら、次の順で更新します。

1. 必要に応じて「バックアップを書き出す」を押します。
2. Chromeのウィンドウをすべて閉じます。
3. 新しいインストーラーを実行します。
4. 完了後に開くChromeの拡張機能画面で、本拡張が有効になっていることを確認します。権限が表示された場合は、[インストール時と同じ4つの接続先](#chromeが権限を表示したとき)を確認します。
5. 古いバージョンが表示されている場合だけ、本拡張の「再読み込み」を1回押します。
6. 拡張で「今すぐ確認」を一度押し、記録画面で画像の進捗を確認します。残りの画像は自動で保存されます。

更新では同じ配置場所を使うため、通常は保存済みの履歴が引き継がれます。Chromeから拡張を削除したり、別のフォルダーを新しく読み込んだりすると、以前の履歴を開けなくなる可能性があります。

## 困ったとき

| 表示や症状 | 次にすること |
| --- | --- |
| 「ログインが必要です」 | 「VRChat公式サイトを開く」からログインし、拡張へ戻って「今すぐ確認」を押します。 |
| 「VRChatが混雑しています」 | 画面に表示された時刻まで待ちます。保存済みの履歴は変わりません。 |
| 「通信できません」 | インターネット接続を確認し、少し時間をあけて「今すぐ確認」を押します。 |
| リストが4個しか表示されない | VRC+用リストへワールドを1件入れた状態で「今すぐ確認」を押します。確認後は最大8枠を表示できます。 |
| 画像を自動保存中・待機中 | Chromeを起動したまま待ちます。表示中の画面を閉じても残りを自動で取得します。「今すぐ確認」を繰り返す必要はありません。 |
| 一部の画像を取得できませんでした | 取得できなかった画像があります。時間をあけて次の確認を行うと再試行します。保存済みの画像と履歴は保持されています。 |
| 更新後も古い版が表示される | Chromeの拡張機能画面で、本拡張の「再読み込み」を1回押します。 |

解決しない場合は、公開して差し支えない症状だけを[GitHub Issues](https://github.com/Na2ki-BB/vrc_favworld_check/issues)へ報告してください。GitHub Issuesは公開されるため、パスワード、2段階認証コード、Cookie、バックアップ内容は手元で管理してください。

## アンインストール

このパソコンから記録と拡張を削除するときは、次の順で進めます。

1. 必要な履歴があれば「バックアップを書き出す」を押します。
2. 「設定とバックアップ」で「記録をすべて削除して拡張を削除」を押します。
3. Chromeから拡張が削除されたあと、Windowsの「インストールされているアプリ」からVRC Favorite World Historyをアンインストールします。

手順2がChrome内のワールド記録と画像を消去し、手順3がWindowsへ配置した拡張ファイルを削除します。書き出したバックアップファイルも消す場合は、保存した場所から削除してください。

## プライバシーと安全性

- ワールド記録と画像は、拡張専用のChrome内データベースへ保存されます。
- 通信先はVRChat公式サイトとVRChat APIです。
- VRChat APIは、お気に入りとワールド情報の読み取りに使います。
- 公式サイトのログイン状態は確認中だけVRChat APIへ渡し、保存対象はワールド記録、画像、設定に限定します。
- JSONバックアップには、ワールド記録、変更履歴、設定が入ります。

詳しいデータの扱いは[プライバシー方針](docs/PRIVACY.md)、安全設計は[セキュリティ設計](docs/SECURITY.md)を参照してください。

## 開発者向け

利用者向けの説明はここまでです。以降は、ソースから検証・配布物作成を行う開発者向けです。

必要環境はNode.js 22以降です。

```bash
npm ci
npm run verify
npm run package
```

`npm run verify` はlint、型検査、テスト、配布内容の安全検査、拡張のビルドをまとめて実行します。`npm run package` はChrome用ZIP、Windowsインストーラー、SHA-256を `artifacts/` へ生成します。Windowsインストーラーの生成にはInno Setup 6が必要です。

# プライバシー方針

画像込みZIPバックアップには、従来JSONの記録に加えて保存済みサムネイルが入ります。パスワード、2FAコード、Cookie、token、session情報は含めません。ZIPも個人用データとして非公開で保管してください。形式と検証境界は[画像込みバックアップ設計](IMAGE_BACKUP.md)に記載します。

最終更新: 2026-08-24

VRC Favorite World Historyは、VRChatのお気に入りワールドを利用者自身のパソコンへ記録するChrome拡張です。この文書では、何を保存し、どこへ通信し、どうすれば消去できるかを説明します。

## 要点

- ワールド記録とサムネイルは、利用中のChromeプロフィール内へ保存されます。
- 通信先は、ログインに使うVRChat公式サイトと、お気に入り情報を読むVRChat APIです。
- ログインはVRChat公式サイトで行います。
- 記録は通常、利用者が拡張の画面から全消去するまで残ります。拡張やChromeプロフィールの削除、端末の初期化・故障では失われることがあります。

## Chrome内へ保存する情報

次の情報を、拡張専用のIndexedDB（Chrome内の保存場所）へ記録します。

| 情報 | 使う目的 |
| --- | --- |
| VRChatのUser IDと表示名 | アカウントごとに記録を分けるため |
| World ID、ワールド名、作者名 | 消えたあとも最後の情報を表示するため |
| お気に入りリストの名前と所属 | 最後にどのリストへ入っていたか確認するため |
| 縮小したワールドサムネイルと取得元URL | 名前だけで思い出せない場合の手掛かりと、画像の更新判断に使うため |
| 確認日時と状態の履歴 | 名称変更、一覧からの消失、アクセス不可、復帰を確認するため |
| 未完の画像保存ジョブ（元API画像URL・試行回数・進捗） | Chrome再起動後も残りの画像を自動保存するため |
| 自動確認・通知の設定 | 利用者が選んだ動作を保つため |
| 同期結果の短い記録 | 失敗時に、次の操作を画面へ案内するため |

サムネイルは最大辺320px、1件48KiB以下のWebPへ縮小し、縮小後の画像を保存します。VRChat APIの応答からは、上の表にある項目だけを保存先へ移します。同期結果の記録は、アカウントごとに直近100件、ログイン確認前の記録は直近20件へ自動的に整理します。ワールド名、状態履歴、保存済みサムネイルは長期記録として残します。

## 開発者が受け取る情報

開発者が受け取るのは、利用者がGitHub Issuesへ自分で投稿した内容です。拡張の記録はChrome内に保存され、同期の通信はVRChatとの間で行われます。

GitHub Issuesへ投稿した内容は公開情報になります。報告内容は公開して差し支えない症状に絞り、パスワード、2段階認証コード、Cookie、トークン、バックアップは手元で管理してください。

## VRChatへのログインとCookie権限

ログインはVRChat公式サイトで、利用者がいつもどおり行います。拡張の「VRChat公式サイトを開く」からログイン画面へ移動できます。

お気に入り情報をVRChat APIから読むには、公式サイトでのログイン状態をAPIでも確認できるようにする必要があります。このため、Chromeは本拡張の導入時にCookie権限を表示します。

拡張が扱うのは、VRChatのログインに使われる固定名 `auth` と、存在する場合の `twoFactorAuth` だけです。確認を始めるときにAPI用ドメインへ一時的に複製し、通常は確認終了時に削除します。一時Cookieの期限は最長15分です。

Cookieの値は、確認中のVRChat APIへ送る一時Cookieとしてブラウザ内で扱います。永続的な保存対象はワールド記録、画像、設定、短い同期結果です。公式サイト側の元Cookieはそのまま保ち、API側で同じ名前のCookieが使われている場合は確認を停止します。

VRChatの利用者情報を確認するAPI応答からは、User IDと表示名を取り出します。保存する項目はこの2つに限定します。

詳しい保護方法と異常終了時の扱いは、開発者向けの[セキュリティ設計](SECURITY.md)に記載しています。

## 外部通信

本拡張が利用する通信先は次のとおりです。

| 通信先 | 用途 |
| --- | --- |
| `https://vrchat.com/home/login` | 利用者が公式サイトでログインするため |
| `https://api.vrchat.cloud/api/1/` | 本人のお気に入り、ワールド情報、リスト、サムネイルを読むため |
| `https://files.vrchat.cloud/` | VRChatの画像APIから転送されるサムネイル本体を読むため |

APIでは読み取り専用のGETリクエストを使い、現在の利用者、お気に入りリスト、ワールド情報、サムネイルを取得します。画像通信にはCookieと参照元を付けません。画像配信先の一時的な署名付きURLは保存せず、元のAPI画像URLだけを画像の更新判断に使います。画像取得のジョブと進捗は対象プロフィール・画像元URL・試行回数・確認時刻とともに端末内に保存し、自動での取得継続に使います。この情報はJSONバックアップには含めません。

VRChat側でのデータ処理には、VRChatの利用規約とプライバシーポリシーが適用されます。

## バックアップ

「設定とバックアップ」から、アカウントごとの記録をJSONファイルへ書き出せます。JSONには次の情報が入ります。

- バックアップ形式、作成日時、このツールのバージョン
- VRChatのUser IDと表示名
- ワールド名、作者名、World ID
- お気に入りリスト名と変更履歴
- ワールドの状態と変更履歴
- 自動確認と通知の設定

サムネイル画像の保存先はChrome内です。JSONを復元した後、アクセスできるワールドの画像は次回の確認で取得します。アクセスできないワールドでは、復元前のChrome内にある保存画像が唯一の記録になります。

JSONの内容は上の一覧に限定されます。お気に入りや表示名を含む個人用ファイルとして、利用者自身が管理できる場所へ保管してください。

復元では、ファイルの大きさ、形式、ID、日時、データ同士の関係を検査し、すべての検査に通った内容だけを記録へ反映します。

## 保存期間と削除

ワールド記録、履歴、サムネイルは、拡張とChromeプロフィールが保たれている間はChrome内に残ります。Chromeから直接拡張を削除する、Chromeプロフィールを削除・初期化する、端末や保存領域が故障すると、記録を失うことがあります。名前と履歴はJSONへ定期的にバックアップできます。サムネイルの保存先はChrome内です。

利用者自身の操作ですべて消す場合は、次の順で進めます。

1. 必要なら「バックアップを書き出す」でJSONを保存します。
2. 拡張の「設定とバックアップ」で「記録をすべて削除して拡張を削除」を実行します。
3. Chromeから拡張が削除されたあと、Windowsの「インストールされているアプリ」から本製品をアンインストールします。

手順2は、新しい確認を止め、拡張専用の記録をまとめて消去してからChrome側の拡張を削除します。消去に失敗した場合は途中の状態で進めず、画面に再試行方法を表示します。

手順2がChrome内の記録と画像を消去し、手順3がインストーラーの配置したファイルを削除します。書き出したJSONは選んだ保存場所に残るため、一緒に消す場合はその場所から削除してください。

端末を譲渡・廃棄するため記憶装置全体を完全に消去したい場合は、Windowsまたは端末メーカーの初期化手順を利用してください。この拡張の削除操作は、通常のアプリ削除までを担当します。

## Windowsインストーラー

インストーラーは、拡張ファイルを現在のWindowsユーザー用フォルダーへ配置します。インストーラーが扱う範囲は、配布物に含まれる拡張ファイルの配置、更新、削除です。

導入する拡張ファイルはインストーラーに同梱されています。利用者が新しいインストーラーを実行したときに更新します。

## Chromeに表示される権限

| 権限 | 利用者に提供する機能 |
| --- | --- |
| `alarms` | Chrome起動中の定期確認と、開始済み画像保存の自動継続 |
| `notifications` | 確定した変化のデスクトップ通知 |
| `unlimitedStorage` | 長期間の履歴をChromeの自動的な容量整理から守る |
| `declarativeNetRequestWithHostAccess` | VRChatが求める識別情報をAPI通信へ付ける |
| `cookies` | 公式サイトのログイン状態を、確認中だけVRChat APIでも利用する |
| `https://vrchat.com/*` | 公式サイトのログインCookieを確認する |
| `https://vrchat.cloud/*` | APIへ影響する同名Cookieがないか安全確認する |
| `https://api.vrchat.cloud/*` | お気に入り情報の取得と、一時Cookieの管理 |

各権限は、上の用途とVRChatの通信先に限定して使います。

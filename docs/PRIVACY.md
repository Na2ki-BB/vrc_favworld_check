# プライバシー方針

最終更新: 2026-10-07

VRC Favorite World Historyは、VRChatのお気に入りワールドを利用者のChrome内へ記録する拡張です。この文書では、保存する情報、通信先、削除方法を説明します。導入・操作手順は[README](../README.md)を参照してください。

## 保存する情報

記録は、拡張を読み込んだChromeプロフィール内の専用データベース（IndexedDB）へ保存します。開発者のサーバーへの送信や、パソコン間の自動同期は行いません。

| 情報 | 用途 |
| --- | --- |
| VRChatのUser ID・表示名 | アカウントごとの記録の区別 |
| World ID・ワールド名・作者名・お気に入りリスト | 最後に確認できた情報の表示と検索 |
| 確認日時・ワールドの状態・変更履歴 | 名前や所属リストの変更、消失・復帰の確認 |
| 縮小したサムネイル・元のAPI画像URL | 保存画像の表示と更新判断 |
| 画像取得待ちの対象・試行回数・進捗・失敗理由の分類 | 画像保存の継続と再試行 |
| 非表示状態・完全削除したWorld ID | 表示状態の維持と、削除済み記録の再表示防止 |
| 自動確認・通知の設定、同期予定、未読状態など | 拡張の動作と表示の管理 |
| 同期結果の短い記録 | 失敗時の状態表示と再試行の判断 |

サムネイルは最大辺320px、1件48KiB以下のWebPとして保存します。画像配信先の一時的な署名付きURLは保存せず、元のAPI画像URLを使います。画像の失敗理由は固定の分類で保存し、例外文、応答本文、ヘッダーは保存しません。

同期結果の記録は、アカウントごとに直近100件、アカウントを確認できる前のものは直近20件に整理します。ワールド記録、変更履歴、保存済み画像を期間で自動削除する機能はありません。

## ログイン情報の扱い

ログインと二段階認証は、VRChat公式サイトで行います。拡張にパスワードや認証コードを入力する必要はありません。

拡張は、公式サイトのログイン状態をVRChat APIでも利用するため、ChromeのCookie権限を使用します。対象は固定名の `auth` と、存在する場合の `twoFactorAuth` です。お気に入りの確認や画面のログイン状態確認を行う間、API用ドメインへ一時Cookieを複製し、通常は処理終了時に削除します。

- 公式サイト側の元Cookieは変更・削除しません。
- API側に競合する同名Cookieがある場合は、上書きせず確認を停止します。
- 一時Cookieには最長15分の期限を設定します。異常終了時は失効を待ちますが、API側がCookieや期限を書き換えた場合は、この時間内の削除を保証できません。
- Cookieの値、パスワード、二段階認証コードは、拡張のデータベース、ログ、バックアップへ保存しません。
- 利用者情報のAPI応答からはUser IDと表示名を取り出します。応答全体は保存しません。

詳細は[セキュリティ設計](SECURITY.md)を参照してください。

## 外部通信

| 接続先 | 用途 |
| --- | --- |
| `https://vrchat.com/home/login` | 利用者が公式サイトでログインするために開くページ |
| `https://api.vrchat.cloud/api/1/` | 現在の利用者、お気に入り、リスト、ワールド情報、サムネイルの取得 |
| `https://files.vrchat.cloud/` | VRChatの画像APIから転送されるサムネイルの取得 |

API通信は読み取り専用のGETです。VRChatのお気に入りを変更するリクエストは送りません。画像取得にはCookieと参照元を付けません。広告・分析・テレメトリー用の通信はありません。

VRChat側のデータ処理には、[VRChatの利用規約](https://hello.vrchat.com/legal)と[プライバシーポリシー](https://hello.vrchat.com/privacy)が適用されます。

## バックアップ

「設定とバックアップ」から、表示中のアカウントの記録と保存済み画像をZIPへ書き出せます。含まれるのは次の情報です。

- バックアップの形式・作成日時・拡張のバージョン
- User IDと表示名
- ワールド名、作者名、World ID、お気に入りリスト、状態、確認日時、変更履歴
- 非表示状態と完全削除後の再表示防止用World ID
- 自動確認・通知の設定
- 記録に対応する保存済みWebPサムネイルと、そのWorld ID・寸法・容量・取得日時・元のAPI画像URL

**未保存の画像、画像取得待ちのジョブ、Cookieやパスワードは含みません。** 書き出し・復元のために画像を再取得する通信は行いません。バックアップは暗号化されておらず、お気に入り情報と画像を含む個人用ファイルです。利用者自身が管理できる場所へ保管してください。

復元時はファイルの大きさ・形式・ID・日時・データ間の関係と画像を検査します。利用者が対象アカウントと件数を確認した後、記録・設定・表示状態・削除済みIDを置き換え、ZIP内の画像を同時に追加・更新します。他アカウントの記録は保持します。古いバックアップに残る名前や履歴が再び表示される場合があります。

ZIPに含まれない既存画像は保持します。ただし、バックアップで完全削除済みとされるIDの画像は消去します。従来のJSON（version 1・2・3）も復元できますが、JSONには画像が含まれません。

## 保存期間と削除

記録は通常、利用者が完全削除するまでChrome内に残ります。ただし、拡張やChromeプロフィールの削除・初期化、端末や保存領域の故障で失われる場合があります。バックアップは保存の保証ではなく、記録と保存済み画像を別のファイルに残す手段です。

| 操作 | 対象と結果 |
| --- | --- |
| カードの「削除」 | 通常の一覧から隠します。名前・画像・履歴は残り、同期と通知も続きます |
| 非表示の記録の「戻す」 | 表示状態を戻します |
| 非表示の記録の「完全に削除」 | 対象ワールドの名前・画像・履歴と取得待ち情報を消去します。再表示防止のWorld IDだけを残します |
| 「記録をすべて削除して拡張を削除」 | 全アカウントの拡張内記録と画像を消去し、Chromeから拡張を削除します |

完全削除後も、通常のお気に入り確認で利用可能なお気に入りとして取得できたワールドは、新しい記録を開始します。古い名前・画像・履歴は復活しません。

利用を終了するときは、必要なバックアップを書き出し、拡張内の全消去を実行してから、Windowsのアプリ一覧で本製品をアンインストールしてください。ZIPで導入した場合は、拡張内の全消去後に配置フォルダーを削除します。詳しい手順は[README](../README.md#利用を終了する)にあります。

Windowsアンインストーラーが削除するのは配置した拡張ファイルです。Chromeの記録や書き出したバックアップは削除しません。不要なバックアップは、利用者が保存先で削除してください。本拡張の削除機能は、記憶装置全体の安全な消去を保証するものではありません。

## Chromeの権限

| 権限・接続先 | 用途 |
| --- | --- |
| `alarms` | 自動確認と、開始済み画像保存の継続 |
| `notifications` | 確定した変化のデスクトップ通知 |
| `unlimitedStorage` | 履歴と画像を長期保存するための容量制限の緩和 |
| `declarativeNetRequestWithHostAccess` | API通信に本拡張を識別する情報を付ける |
| `cookies` | 公式サイトのログイン状態の一時利用 |
| `https://vrchat.com/*` | 公式サイトのログインCookieの確認 |
| `https://vrchat.cloud/*` | APIへ影響する親ドメインの同名Cookieの確認 |
| `https://api.vrchat.cloud/*` | APIの読み取りと一時Cookieの管理 |
| `https://files.vrchat.cloud/*` | サムネイル画像の取得 |

## Windowsインストーラー

インストーラーは、同梱された拡張ファイルを現在のWindowsユーザー用の固定フォルダーへ配置します。利用者が新しいインストーラーを実行すると更新します。Chromeのプロフィール、Cookie、データベースを探索・変更せず、VRChatへの認証や通信も行いません。

## 問い合わせ

拡張が記録を開発者へ自動送信することはありません。[GitHub Issues](https://github.com/Na2ki-BB/vrc_favworld_check/issues)へ投稿した内容は公開されます。問い合わせは公開して差し支えない症状に限定し、パスワード、二段階認証コード、Cookie、トークン、バックアップを投稿しないでください。

この方針を変更した場合は、最終更新日を改めます。
